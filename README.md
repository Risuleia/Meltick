## What is Meltick?

Meltick is a minimal clock screensaver for Windows built around a liquid glass aesthetic.

The clock displays the current time through two large glass cards, with digits that roll and deform as they change. The cards use fluid stretch and squash motion to give the transitions a physical, elastic feel rather than simply switching from one number to another.

Meltick supports:

- **Liquid glass clock** — translucent glass cards with a soft, refractive appearance.
- **Fluid digit transitions** — changing digits roll vertically with animated deformation.
- **Spring-based motion** — the cards react with elastic stretch and squash physics.
- **12 / 24-hour formats** — switch between standard 24-hour time and 12-hour time with AM/PM.
- **Multi-monitor support** — runs independently across connected displays.
- **Live configuration** — adjust the clock format and scale through the screensaver settings.
- **Windows screensaver integration** — works directly with the standard Windows screensaver interface.
